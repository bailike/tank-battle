# 坦克大战 (Tank Battle)

一款基于 HTML5 Canvas 的经典坦克大战浏览器游戏。消灭所有敌方坦克即可进入下一关，挑战更高难度。

## 快速开始

直接用浏览器打开 `tank-battle.html` 即可开始游戏，无需安装任何依赖。

## 操作说明

| 按键 | 功能 |
|------|------|
| `↑` / `W` | 前进 |
| `↓` / `S` | 后退 |
| `←` / `A` | 左转（需松开前进/后退键） |
| `→` / `D` | 右转（需松开前进/后退键） |
| `空格` / `J` | 开火 |
| `R` | 游戏结束后重新开始 |

## 玩法规则

### 核心目标
消灭当前关卡中的所有敌方坦克，即可自动进入下一关。

### 生命系统
- 初始生命值：**3 条**
- 被敌方子弹击中或与敌方坦克碰撞，生命减 1
- 受到伤害后有 **90 帧（约 1.5 秒）无敌时间**，期间坦克闪烁并有护盾光环
- 生命归零则游戏结束

### 地图元素
- **边框墙**（深灰色）：不可破坏，构成游戏区域边界
- **钢铁墙**（浅灰色，带交叉纹理）：不可破坏，分布在场地内部，4 种随机布局
- **砖块墙**（棕色）：可被子弹破坏，生命值 2 点
- 每关随机生成一种砖块布局（十字形 / L 形 / 散落 / 通道）和一种钢铁布局

### 敌方坦克
- 随机从地图四边出生
- 具有随机移动 AI，偶尔会追踪玩家
- 自动向玩家方向射击
- 生命值随关卡提升：`1 + floor(level / 2)`
- 移动速度随关卡提升：`1 + level × 0.3`

### 关卡系统
- 每关敌人数量：`3 + level × 2`
- 进入新关卡时：
  - 玩家火力等级 +1（最高 4 级）
  - 重新生成墙体布局
  - 获得 60 帧无敌保护
  - 玩家位置重置到出生点

### 火力等级
| 等级 | 每发子弹破坏力 |
|------|---------------|
| 1 | 1 点 |
| 2 | 2 点 |
| 3 | 3 点 |
| 4（满级） | 4 点 |

### 计分规则
- 每消灭一个敌方坦克：**+100 分**
- 关卡越高，敌人越多，得分越快

## 技术实现

- **纯前端**：HTML + CSS + JavaScript (Canvas API)
- **无依赖**：不依赖任何第三方库或框架
- **Canvas 渲染**：60fps 游戏循环，requestAnimationFrame 驱动
- **碰撞检测**：AABB 矩形碰撞算法
- **粒子系统**：爆炸时生成 15 个粒子，模拟火光效果
